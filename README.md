# A Casa di Lidia Numana

Sito web per il **Bed & Breakfast e Appartamenti sul lungomare di Numana** (AN), realizzato con Next.js e Tailwind CSS.

## Tech Stack

- **Next.js** — React framework (App Router)
- **Tailwind CSS** — utility-first CSS
- **TypeScript** — type safety
- **Formspree** — form backend (richiesta disponibilità)
- **Google Fonts (Quicksand)** — typography

## Sezioni

- Hero — parallax fullscreen con logo e glassmorphism
- Intro — presentazione e statistiche
- Valori — servizi in icone circolari
- Camere — 3 camere (Corallo, Indaco, Oltremare) con carosello inline auto-play
- Appartamenti — carosello inline + griglia servizi
- Spiagge — 3 card editoriali (Due Sorelle, Spiaggia del Frate, Spiaggiola)
- Recensione — social proof TripAdvisor
- Richiedi Disponibilità — form via Formspree
- Footer — contatti, CIN, logo

## Sviluppo

```bash
npm run dev
```

Apri [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```

## Deploy

Su Vercel: `npx vercel`
